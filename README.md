# Cipher Rush

A review site for the Cybersecurity Essentials final. It has three modes:

- **Timed**: a game-show style run with speed scoring, streaks and an explanation after every question.
- **Classic exam**: no timer, 50 questions plus 6 drag-and-drop items, scored when you submit.
- **Practice exam**: same as Classic, but each answer is marked as soon as you submit it.

Everything runs in the browser. Scores and progress are saved locally on each device.
