# Cipher Rush

A review site for the Cybersecurity Essentials final. The 50 questions and answer choices come from the [reference exam](https://itexamanswers.net/cybersecurity-essentials-course-final-exam-answers.html), verbatim. Every explanation is rewritten to say why its answer is right.

- **Timed**: a game-show style run with speed scoring, streaks and an explanation after every question.
- **Classic exam**: no timer, the 50 exam questions plus the 6 drag-and-drop items, scored when you submit.
- **Practice exam**: same as Classic, but each answer is marked as soon as you submit it.

Everything runs in the browser. Scores and progress are saved locally on each device.
