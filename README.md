# Cipher Rush

A review site for the Cybersecurity Essentials final. The 50 questions and answer choices come from the [reference exam](https://itexamanswers.net/cybersecurity-essentials-course-final-exam-answers.html), verbatim.

- **Timed**: a game-show style run with speed scoring, streaks and an explanation after every question.
- **Classic exam**: the 50 exam questions in order, no timer, scored when you submit.
- **Practice exam**: same as Classic, but each answer is marked as soon as you submit it.
- **Match drill**: 6 drag-and-drop matching items on the same topics, kept separate from the exam score.

Everything runs in the browser. Scores and progress are saved locally on each device.
